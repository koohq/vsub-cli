# コード品質およびテスト規範 (Quality & Testing Guidelines)

このプロジェクト（`vsub-cli`）では、自動化された品質ゲート（`.agents/hooks.json`）と Vitest 単体テストスイートによってコード品質を厳格に管理しています。

## 1. 単体テストの義務付け
- **機能追加・バグ修正時**:
  - コード変更を行う際は、必ず対応するテスト（`src/*.test.ts`）を追加または更新すること。
  - テストの追加や修正なしにロジック変更を完了してはならない。
- **純粋関数のテスト**:
  - `src/srt.ts`（字幕パース/再構築）、`src/config.ts`（設定解決優先順位）、`src/groq.ts`（時間計算/言語コード正規化）などのユーティリティ関数は、境界値やエッジケースを含めて徹底的にテストすること。
- **外部 API / 外部プロセスのモック**:
  - Groq API、Gemini API、FFmpeg 外部プロセス（`execa`）に依存するテストは、`vi.mock` を用いてモック化し、オフラインかつ高速に実行できるようにすること。

## 2. 完了前の自己検証
作業完了前には、必ず以下のコマンドがすべて成功することを確認すること:
1. `pnpm run check`: Biome による構文・リント・フォーマット検証
2. `pnpm run build`: TypeScript (`tsc`) による厳格な型整合性チェック
3. `pnpm run test`: Vitest による全単体テストスイートの通過

> [!NOTE]
> エージェントが作業終了（Stop）しようとすると、自動的に `scripts/quality-gate.mjs` が実行され、上記3点のいずれかが失敗した場合は自動的に自己修復ループがトリガーされます。
